# GitBot Companion

An ultra-lightweight GitHub Automation & Sync Discord Bot and Local Companion Daemon. Designed for multi-repository monitoring, automated backups, and scheduled local pulls with Discord Components V2 integration.

---

## Features

- **All-in-One Daemon**: Integrates Discord gateway, local filesystem tasks, Git CLI operations, and GitHub REST API into a single lightweight Node.js daemon.
- **Discord Components V2 Native**: Uses modern Discord Components V2 containers, sections, text displays, and action rows without deprecated embed structures.
- **Automated Directory Backup (`/github sync`)**: Synchronizes designated local workspace folders directly into remote GitHub repositories with automatic git initialization, commit creation, and branch pushes.
- **Multi-Repository Change Tracker (`/github track`)**: Periodically monitors target repositories for commits and releases, delivering alerts directly to designated Discord channels.
- **Scheduled Automated Puller (`/github autoget`)**: Periodically checks and pulls latest remote changes to local target directories.
- **Cross-Platform Background Daemon**:
  - **Windows**: Silent background execution via VBScript (`run-silent.vbs`) and startup registry persistence (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
  - **Linux**: Standard `systemd` user service setup.
  - **macOS**: `LaunchAgents` plist daemon integration.
- **Cloudflare Worker Keep-Alive Watchdog**: Built-in pinging service to keep Cloudflare Worker edge functions warm and awake.

## Prerequisites

- **Node.js** >= 18.0.0
- **Git** installed and available in your system PATH
- **Discord Bot Token & Client ID** (from Discord Developer Portal)
- **GitHub Personal Access Token** (Classic or Fine-Grained with repo read/write access)

## Installation & Setup

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/NotRainYuu/gitbot.git
cd gitbot
npm install
```

### 2. Configure Environment

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Edit `.env` with your credentials:

```env
DISCORD_TOKEN=your_discord_bot_token_here
CLIENT_ID=your_discord_application_client_id
GUILD_ID=
GITHUB_TOKEN=ghp_your_github_personal_access_token
PREFIX=.sync
TRACK_INTERVAL_MINUTES=30
AUTOGET_INTERVAL_MINUTES=5
CF_WORKER_URL=
CF_WORKER_PING_INTERVAL_SECONDS=120
CF_WORKER_AUTO_WAKEUP=true
```

### 3. Deploy Discord Slash Commands

Deploy the registered slash commands to Discord:

```bash
npm run deploy-commands
```

### 4. Build TypeScript

Compile the project to JavaScript:

```bash
npm run build
```

## Running the Application

### Development Mode

Run with live reloading using `tsx`:

```bash
npm run dev
```

### Production / Foreground Mode

```bash
npm start
```

### Windows Silent Background Mode

Run the daemon in the background without terminal windows:

```bash
npm run start:silent
```

To stop all background processes:

```bat
scripts\stop-background.bat
```

## Autostart on Boot

Manage persistent autostart across Windows, Linux, and macOS using `scripts/autostart.js`:

```bash
# Enable autostart on boot
npm run autostart:install

# Check autostart status
npm run autostart:status

# Disable autostart
npm run autostart:uninstall
```

## Discord Commands Reference

| Command | Description |
| :--- | :--- |
| `/github sync` | Interactive wizard to initialize, commit, and push a local folder to a GitHub repository |
| `/github track` | Add a repository to the watch list for commit and release notifications |
| `/github autoget` | Configure scheduled automated pulls from a remote repository to a local path |
| `/github list` | List all active tracking and automated pull tasks |
| `/github untrack` | Remove a repository from the watch list |
| `/github unautoget` | Stop scheduled automated pulls for a repository |
| `.sync` (Prefix) | Quick trigger shortcut for folder synchronization |
